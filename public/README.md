# AAA Documentation

> **For External Users** - Quick start guide for using AAA (AI Agent Architecture)

## 🤖 For AI Agents

**Recommended**: Connect via MCP server
```bash
npx @aaa/mcp-server
```

**Fallback**: Use CLI
```bash
npm install -g @aaa/cli
aaa init my-project
```
