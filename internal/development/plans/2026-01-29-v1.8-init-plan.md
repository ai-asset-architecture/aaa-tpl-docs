# Implementation Plan: v1.8 Observability 2.0

## Goal Description
Implement **Observability 2.0** to transform governance from "snapshot reports" to "historical trends".
1.  **Time-Series Metrics**: Track `compliance_score`, `drift_rate`, and `repo_health` over time.
2.  **Risk Ledger**: An append-only, tamper-evident log of all governance events (audits, policy failures, manual overrides).
3.  **Trend Dashboard**: Visualize valid historical data.

## User Review Required
> [!IMPORTANT]
> **Storage Strategy**: We will use a local SQLite database (`.aaa/observability.db`).
> **Privacy**: `RiskLedger` must sanitize secrets (regex) before writing.
> **Retention**: `MetricStore` must auto-prune data > 90 days on init.
> **Schema**: DB must include `metadata` table with `schema_version=1`.

## Proposed Changes
### [aaa-tools]
#### [NEW] aaa/observability/custom_metrics.py
- Define `MetricStore` class using SQLite.
- **Schema Management**: Create `metadata` table (`schema_version=1`).
- **Retention**: Implement `prune(days=90)` method called on `__init__`.
- Schema: `timestamp`, `metric_name`, `value`, `tags (JSON)`.

#### [NEW] aaa/observability/ledger.py
- Define `RiskLedger` class.
- **Privacy Firewall**: Implement `_sanitize(text)` using Regex for common secrets (AKIA, etc).
- Schema: `timestamp`, `event_type`, `severity`, `description`, `actor`, `hash`.
#### [MODIFY] aaa/cmd/audit_commands.py
- Integrate `MetricStore.record()` into `audit` command.
- Integrate `RiskLedger.record()` into `audit` command (failures/overrides).
#### [NEW] aaa/cmd/observability_commands.py
- `aaa observe trends` (Show ASCII trend chart).
- `aaa observe ledger` (Show risk log).

## Triple-Summary Protocol (v1.8)
### 1. Strategic Plan (戰略計畫摘要)
Shift from "Point-in-Time" to "Time-Series" governance. Enable managers to see "Are we getting better or worse?".

### 2. Schema Evolution (結構演進摘要)
New `.aaa/observability.db` (SQLite) introduces stateful storage beyond JSON files. Requires `sqlite3` (std lib).

### 3. Component Architecture (組件架構摘要)
New `aaa.observability` package. Decoupled from `aaa.engine` but invoked by `aaa.cmd`.

- `tests/observability/test_ledger.py`: Verify tamper-evidence (hash chain basic).
### Manual Verification
