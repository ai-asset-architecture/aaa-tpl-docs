# AAA v0.5 Runtime Engine Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Implement a minimal runbook runtime in `aaa-tools` so `aaa run ops/complete-milestone` executes fs/evals/index/notify actions with stdout notifications.

**Architecture:** Add a runtime executor that loads runbooks via registry, performs basic `{{ }}` templating, dispatches actions, and records step outputs. Implement core actions (`fs_write`, `fs_update_frontmatter`, `aaa_evals.run`, `notify`, `governance.update_index`) with structured stdout logging.

**Tech Stack:** Python 3, unittest, JSON, subprocess.
