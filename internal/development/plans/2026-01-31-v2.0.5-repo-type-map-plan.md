# Implementation Plan: v2.0.5 Repo Type Map SSOT + Soft Enum

## Goal Description
Establish a single source of truth for repo_type mapping in aaa-actions and add soft-enum warnings in nightly to improve drift observability without breaking consumers.

## User Review Required
> [!IMPORTANT]
> - **SSOT Location**: Use `aaa-actions/.aaa/repo_type_map.json` as the single source of truth (Step 1).
> - **Allowed Types (Soft Enum)**: Use the full allowed type list including `audit` and `workspace`.
> - **Enforcement Scope**: Soft enum checks only in nightly workflow (WARN), repo-checks strictness deferred.

## Proposed Changes
### [aaa-actions]
#### [NEW] .aaa/repo_type_map.json
- Define repo_name → repo_type mapping for nightly scope repos.
- Include full allowed type list (governance/policies/audit/workspace/docs/templates/tooling/actions/evals/observability/prompts/registry/service/frontend).
- **JSON shape (fixed)**:
  - `version`
  - `allowed_types: []`
  - `repo_type_map: { "<repo>": "<type>" }`

#### [MODIFY] .github/workflows/nightly-governance.yaml
- Load repo_type_map.json as SSOT for plan generation.
- Emit `WARN unknown_repo_type repo=<repo> value=<value>` when repo_type not in allowed list.
- Fail fast if mapping missing for any nightly repo with token `ERROR missing_repo_type_mapping repo=<repo>`.
- Explicitly document that nightly scope repo list is the workflow-defined repo list (the static repo array used to build the nightly plan), with ordering preserved as declared in the workflow.

### [aaa-tpl-docs]
#### [MODIFY] .github/workflows/nightly-trigger.yaml
- Bump nightly to new aaa-actions tag v2.0.5.

## Triple-Summary Protocol (v2.0.5)
### 1. Strategic Plan (戰略計畫摘要)
將 repo_type 的信任邊界規則收斂為單一真相，降低 nightly 漂移風險；同時以 soft enum 先做可觀測，不擴大破壞面。

### 2. Schema Evolution (結構演進摘要)
repo_type 仍為 string；新增允許清單的 soft enum 檢查（WARN），並新增 map 覆蓋率 fail-fast。

### 3. Component Architecture (組件架構摘要)
nightly workflow 讀取 repo_type_map.json 建 plan；對未知 type 產生 WARN token；缺 mapping 直接 fail。

## Verification Plan

### Observability Signals

### Manual Verification
- Trigger nightly-governance and confirm repo_type alignment with metadata.
