# Implementation Plan: v1.7 Federated Governance

## Goal Description
Implement the "Federated Governance" pillar to enable cross-organization trust and supply chain security.
This release focuses on:
1.  **Remote Audit**: Verify external repositories' compliance via `aaa audit --remote <url>`.
2.  **Supply Chain Governance**: Dependencies (Packs/Repos) must verify against a trusted signature or checksum.
3.  **Org Ruleset Inheritance**: Allow child workspaces to inherit and selectively override parent organization rulesets.

## User Review Required
> [!IMPORTANT]
> **Trust Anchor**: We need to define where the "Root Trust" comes from. For now, we will assume a known GPG or HTTPS authority.
> **Inheritance Strategy**: Shallow merge vs Deep merge for rulesets. We will assume "Deep Merge" (Child overrides specific keys).

## Proposed Changes

## Triple-Summary Protocol (v1.7)
### 1. Strategic Plan (戰略計畫摘要)
Evolve AAA from "Single Org" to "Inter-Org" trust. Enable "Software Supply Chain" verification where downstream dependencies prove their own governance compliance before being accepted.

### 2. Schema Evolution (結構演進摘要)
- `registry_index.json`: Add `signature` field for Packs.
- `audit_report.json`: Add `signature` and `timestamp` integrity fields.

### 3. Component Architecture (組件架構摘要)
- **Verifier**: New component in `aaa-tools` core to handle HTTP/Git fetching of remote assets.
- **Merger**: New utility for deep-merging YAML/JSON configurations for inheritance.
