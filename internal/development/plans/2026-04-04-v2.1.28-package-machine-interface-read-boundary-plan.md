## Objective
建立 `v2.1.28` 的 Step1 契約基線，將 package runtime 暴露為 machine-readable read boundary。
本版屬 `offering_package_runtime_enablement_line`；可引用 shared canonical law，但不得重新定義、覆寫或吸收 `v2.1.1` 到 `v2.1.27` 的 primary scope；本版只定義 machine-readable read boundary，不宣稱 full AI-facing runtime orchestration，也不帶入 remote session semantics。

## Acceptance Criteria
1. schema 必須以 machine-checkable 方式定義 package machine read boundary，不允許 prose-only fallback。
2. schema 必須明確列出 exposed payload classes，且 read boundary 僅限 selection、resolved definition、prerequisite verdict、status、evidence refs。
3. 本版不得宣稱 full AI-facing runtime orchestration，也不得帶入 remote session semantics。
4. 本版只建立 machine-readable read boundary，不得擴張為第二套主權 interface surface。
5. fail example 必須表達至少一個 write-capable boundary，以及至少一個宣稱 remote session / orchestration semantics 的違規情形。
6. 本版必須明確聲明其僅消費既有 contract，不得出現隱性 primary law 增殖。
7. `version_index.md` 已追加 `v2.1.28` Step1 row，狀態為 `UNVERIFIED` 且 `run_ref=N/A (step2-pending)`。
8. `version_index.md` 的 `status` / `run_ref` / step wording 必須使用 canonical phrase，不得出現同義改寫。

## Out of Scope (Step1)
- 本版只建立 Step1 runtime-plane baseline，不實作 runtime entry / validator / CLI wiring / frontend publish / workflow artifact。
- 不建立 remote session、websocket、distributed control plane 或 AI orchestration。
- 不修改 `aaa-tools`、`aaa-docs`、`aaa-tpl-frontend`、`aaa-evals` 或任何 runtime domain code。

## Risks
- 若 machine interface 不先限制為 read boundary，後續很容易在 package 線過早引入 AI orchestration 與 remote session 複雜度。
- 若 exposed payload 不先固定，CLI / local machine interface / future AI consumer 很容易各長一套接口。

## Triple-Summary Protocol (v2.1.28)
### 1. Strategic Plan (戰略計畫摘要)
先把 package runtime 開成穩定可讀接口，讓 machine consumer 能直接取用 selection/resolution/gate/status/evidence，而不必回頭讀 README。

### 2. Schema Evolution (結構演進摘要)
新增 `package-machine-interface-read-boundary.v0.1.schema.json`，固定 exposed payload classes、read-only boundary 與 non-orchestration 限制。

### 3. Component Architecture (組件架構摘要)
Step1 僅交付 machine read boundary bundle 與 pass/fail fixtures；Step2 若啟動，才把此 bundle 對應到 `aaa-tools` machine-readable interface。
