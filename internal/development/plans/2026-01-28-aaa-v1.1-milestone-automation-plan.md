# v1.1 Milestone Automation & Governance Enhancements Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Automate the manual overhead of milestone lifecycle management (init/complete) and formalize the test coverage strategy proposed in v1.0 to ensure consistent enterprise-grade validation.

**Architecture:** 
1. **Milestone Orchestrator**: New runbooks in `aaa-tools/runbooks/ops/` (`init-milestone`, `complete-milestone`) that automate:
   - Directory creation in `internal/development/milestones/`.
   - Template instantiation from `templates/` with context injection.
   - Auto-registration to `internal/index.json` (SSOT).
2. **Policy Engine**: Formalized `Test Coverage Policy` integrated into the `aaa-tpl-docs` templates and enforced via `aaa check`.
3. **Asset Navigator**: A centralized index for developers located at `internal/development/README.md`, generated from `index.json`.

**Tech Stack:** Python 3.x (Typer CLI), AAA Runbook Engine (v0.5), Markdown Templates.

**Step 1: Write failing tests for Idempotency & Context Injection**
```python
import unittest
from pathlib import Path
from aaa.ops.milestone_manager import init_milestone

class TestMilestoneOps(unittest.TestCase):
    def test_init_milestone_is_idempotent(self):
        # Should not crash if dir exists, should skip or warn
        workspace = Path("/tmp/aaa_test_idempotent")
        init_milestone("v1.1", workspace)
        result = init_milestone("v1.1", workspace)
        self.assertEqual(result["status"], "skipped_or_warned")

    def test_context_injection(self):
        # Verify Date and Author (from git config) are injected
        workspace = Path("/tmp/aaa_test_context")
        init_milestone("v1.1", workspace)
        content = (workspace / "internal/development/milestones/v1.1/PRD.md").read_text()
        self.assertIn("Author:", content)
        self.assertIn("Date:", content)
```

**Step 2: Implement `init-milestone` logic**
- **Path**: `internal/development/milestones/{{inputs.milestone_id}}/`
- **Actions**:
  1. Check existence (idempotency logic).
  2. Copy `templates/PRD-template.md`.
  3. Inject Git Author/Current Date.
  4. Register to `internal/index.json` (Ensure SSOT alignment).

**Step 3: Commit**
```bash
git add aaa-tools/runbooks/ops/init-milestone.yaml aaa/ops/milestone_manager.py
git commit -m "feat(ops): add idempotent init-milestone with context injection"
```
