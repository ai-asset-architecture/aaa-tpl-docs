# v1.1 Milestone Automation & Governance Enhancements Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Automate the manual overhead of milestone lifecycle management (init/complete) and formalize the test coverage strategy proposed in v1.0 to ensure consistent enterprise-grade validation.

**Architecture:** 
1. **Milestone Orchestrator**: New runbooks in `aaa-tools/runbooks/ops/` (`init-milestone`, `complete-milestone`) that automate directory creation, template instantiation, and report generation.
2. **Policy Engine**: Formalized `Test Coverage Policy` integrated into the `aaa-tpl-docs` templates and enforced via `aaa check`.
3. **Asset Navigator**: A centralized index for all 6 asset catalogs to improve developer self-service.

**Tech Stack:** Python 3.x (Typer CLI), AAA Runbook Engine (v0.5), Markdown Templates.

**Files:**

- Create: `aaa-tools/runbooks/ops/complete-milestone.yaml`

**Step 1: Write the failing test (Directory & Template Generation)**
```python
import unittest
from pathlib import Path
from aaa.runbook_runtime import execute_runbook

class TestMilestoneOps(unittest.TestCase):
    def test_init_milestone_creates_structure(self):
        # Setup mock workspace
        workspace = Path("/tmp/aaa_test_milestone")
        workspace.mkdir(parents=True, exist_ok=True)
        
        # Runbook inputs
        inputs = {"milestone_id": "v1.2", "workspace_root": str(workspace)}
        
        # This should fail if runbook or logic is missing
        result = execute_runbook("ops/init-milestone", inputs)
        
        self.assertTrue((workspace / "milestones/v1.2").is_dir())
        self.assertTrue((workspace / "internal/development/plans").is_dir())
```

**Step 2: Run test to verify it fails**
Run: `python3 -m unittest tests.test_milestone_ops -v`
Expected: FAIL (runbook not found)

**Step 3: Implement `init-milestone.yaml`**
Define steps to:
1. `mkdir -p milestones/{{inputs.milestone_id}}`
2. `cp templates/PRD-template.md milestones/{{inputs.milestone_id}}/PRD.md`
3. `mkdir -p internal/development/plans`

**Step 4: Run test to verify it passes**
Run: `python3 -m unittest tests.test_milestone_ops -v`
Expected: PASS

**Step 5: Commit**
```bash

git commit -m "feat(ops): add init-milestone runbook"
```
