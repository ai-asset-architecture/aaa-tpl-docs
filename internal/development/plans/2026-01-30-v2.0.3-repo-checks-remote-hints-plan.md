# Implementation Plan: v2.0.3 Remote Repo-Checks Hints (Phase 1)

## Goal Description
Introduce a post-init hint for repo-checks in the AAA CLI runtime output (Phase 1 of remote user AI guidance). This makes the requirement visible at the moment a repo is created/initialized, reducing missed governance validation by humans or agents. This plan only covers Phase 1 (CLI hint) and explicitly defers MCP/A2A additions (Phases 2/3).

## User Review Required
> [!IMPORTANT]
> 1) This plan only implements the CLI runtime hint (Phase 1). MCP/A2A hints are deferred and must be logged for later execution.
> 2) The hint must be non-blocking and must not alter repo-checks behavior, only messaging.
