# Implementation Plan: v1.5 Self-Healing Engine

## Goal Description
**Strategic Intent**: Shift from "Passive Reporting" to "Active Repair".
Enables `aaa gate --auto-fix` to automatically resolve common governance violations (e.g., missing dependencies, format errors) and introduces `Semantic Checks` using LLMs for "intent-based" governance.

## User Review Required
> [!IMPORTANT]
> **Semantic Cost**: Enabling Semantic Checks will introduce LLM token costs. Default strategy (Hybrid Filter): "Regex First" (scan for keywords) -> "LLM Escalation" (only on ambiguity/match).
> **Auto-Fix Safety (Circuit Breaker)**:
> - **Max Retries**: 3 attempts per violation.
> - **Stability Check**: Verify no syntax errors after fix.
> - **Rollback**: Auto-revert if verification fails.

## Triple-Summary Protocol (v1.5)
### 1. Strategic Plan (戰略計畫摘要)
*   **Pivot**: From "Guardian" (Watch) to "Healer" (Fix).
*   **Design**: "Intent-First". Using LLM to understand *why* a rule failed, not just *that* it failed.

### 2. Schema Evolution (結構演進摘要)
*   **New**: `FixResult` schema (Success, ChangedFiles, ConfidenceScore).

### 3. Component Architecture (組件架構摘要)
*   **Repair Loop**: `Check` -> `Fail` -> `Identify Handlers` -> `Apply Fix` -> `Re-Check`.
