# Implementation Plan: v2.0 The Agent OS

## Goal Description
**The Final Milestone of Phase 1.**
Transform AAA from a "Governance Tool" into a full **"Agent Operating System"**.
This release unifies all previous capabilities (v1.1-v1.9) into a cohesive runtime where Agents is "First-Class Citizen".
Key capability: **Self-Governing Autonomy**.

## Triple-Summary Protocol (v2.0)
### 1. Strategic Plan (戰略計畫)
-   **Objective**: Enable "Governance-Driven Autonomy". Agents don't just follow rules; they *wield* them.
-   **Mechanism**:
    -   **The Trinity**: Unified interface for `aaa check` (Guardian), `registry query` (Semantic), and `court file` (Constitution).
    -   **Trust Network**: `aaa trust` command to verify external repos.
    -   **Certification**: Automated scoring (Bronze/Silver/Gold).
-   **Value**: Breaks the "Trust Ceiling". Enterprises can deploy Agents safely because AAA guarantees the guardrails.

### 2. Schema Evolution (結構演進)
-   `aaa/os/kernel.py`: New unified entry point (`The Agent OS Kernel`).
-   `aaa/trust/chain.py`: Logic for verifying supply chain signatures.
-   `registry_index.json`: Add `certification` metadata schema.

### 3. Component Architecture (組件架構)
-   **aaa-tools/aaa/os/**: The "Kernel" that orchestrates Linter, Gate, and Court.
-   **aaa-tools/aaa/trust/**: Supply Chain Verification.
-   **CLI**:
    -   `aaa os boot`: Initialize the Agent OS runtime.
    -   `aaa trust verify`: Verify remote repo signature.
    -   `aaa cert status`: View current certification level.
