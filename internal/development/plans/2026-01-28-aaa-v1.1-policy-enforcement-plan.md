# v1.1 Automated Policy Enforcement Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Implement automated enforcement of the [Test Coverage Policy](file:///Users/imac/Documents/Code/AI-Lotto/AAA_WORKSPACE/aaa-tpl-docs/internal/development/policies/test-coverage-policy.md) within the `aaa check` workflow to ensure all milestone completions are auditable and compliant.

**Architecture:** 
1. **Governance Check**: A new check script in `aaa-evals` that validates the integrity of milestone completion reports.
2. **CLI Integration**: Integration of this check into `aaa-tools`'s `check` command.
3. **Blocking Logic**: Ensuring non-compliant reports block the `verify-ci` and `blocking` modes.

**Tech Stack:** Python 3.x, AAA Evals Runner, Git.

**Files:**
- [NEW] `aaa-evals/runner/checks/check_test_policy_compliance.py`
- [MODIFY] `aaa-evals/runner/run_repo_checks.py`

**Step 1: Write failing tests for Policy Compliance**
We will simulate a repo with a "completed" milestone but missing the `Test Coverage Appendix`.

**Step 2: Implement Check Logic**
- Verify `internal/index.json` exists.
- For each milestone with `status: "completed"`:
    - Verify `internal/development/milestones/<id>/completion_report.md` exists.
    - Verify the file contains the string `## Test Coverage Appendix`.
- Return `pass: False` and details if any rule is violated.

**Step 3: Register in Runner**
Add `test_policy_compliance` to the `run_repo_checks.py` mapping.
