## Triple-Summary Protocol

### 1. Plan Summary
本計畫旨在將 AAA 從「檢測工具」提升為「開發協定」。透過在 `aaa-tools` 中引入新的輸出格式化層，我們將為 AI Agent 提供包含「失敗原因、引用規則、修補建議」的語義化上下文。這將直接支持 Roadmap 中的「Agent 故障排除成功率 >= 80%」指標。

### 2. Schema Summary
- **Input**: `aaa check --format [json|llm|human]`
- **Output (LLM)**: Markdown 格式，包含 `<RULE>`, `<VIOLATION>`, `<SUGGESTION>` 標籤。
- **Output (JSON)**: 符合 v1.1 定義的標準結構（包含詳細 details 陣列）。

### 3. Component Summary
- `aaa-tools`: 核心變更點，負責數據採集與語義格式化。
- `output_formatter`: 新增組件，解耦業務邏輯與顯示邏輯，便於未來擴充更多 LLM 格式（如 XML）。

## Verification Plan
### Automated Tests
- 執行 `aaa check --format=llm` 並檢查輸出是否包含語義化建議。
- 負向測試：人為製造 README 缺失，驗證 Agent 是否能根據 LLM 輸出給出的建議修復問題。

### Manual Verification
- 驗證 `--format=json` 的向下相容性。
