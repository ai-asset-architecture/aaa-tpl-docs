# v1.2 Registry Schema Specification (v2.0)

> This document defines the schema for `registry_index.v2.json` and Manifest v2.

## 1. Version Handshake Strategy

Root-level meta fields to ensure client compatibility and "Fail Fast".

```json
{
  "schema_version": "2.0",
  "min_cli_version": "1.2.0",
  "last_updated": "2026-01-28T20:00:00Z",
  "comment": "Semantic Registry Schema v2 (Object-Centric)",
  ...
}
```

- Clients with version `< min_cli_version` MUST error out immediately with upgrade instructions.
- `schema_version` allows future parsers to handle migration.

## 2. Object-Centric Topology

Introduction of `object_types` to define governance templates.

```json
{
  "object_types": {
    "service": {
      "display_name": "Backend Service",
      "description": "API-first microservices requiring contract testing and observability.",
      "inherited_packs": ["core-governance", "api-standards"],
      "recommended_evals": ["lint-openapi", "check-health-endpoint"]
    },
    "library": {
      "display_name": "Shared Library",
      "description": "Reusable code modules requiring versioning and rigorous unit testing.",
      "inherited_packs": ["core-governance", "semver-policy"],
      "recommended_evals": ["test-coverage-90", "check-changelog"]
    },
    "data-pipeline": {
      "display_name": "Data Pipeline",
      "description": "ETL/ELT jobs requiring schema validation and data quality checks.",
      "inherited_packs": ["core-governance", "data-quality"],
      "recommended_evals": ["validate-dbt-schema"]
    },
    "infra-as-code": {
      "display_name": "Infrastructure as Code",
      "description": "Terraform/K8s manifests requiring security scanning.",
      "inherited_packs": ["core-governance", "security-baseline"],
      "recommended_evals": ["trivy-scan", "check-terraform-fmt"]
    }
  }
}
```

## 3. Semantic Capabilities (Natural Language)

Pack definitions now include specific capabilities for RAG/Vector search.

```json
{
  "packs": {
    "agent-safety": {
      "version": "1.0.0",
      "capabilities": [
        "prevents file system access outside sandbox",
        "detects potential prompt injection attacks",
        "blocks unauthorized network egress"
      ],
      "object_type_compatibility": ["service", "data-pipeline"],
      "source": "github:ai-asset-architecture/aaa-packs//agent-safety"
    }
  }
}
```

## 4. Migration Strategy (Dual-Publish)

During buffer period (2-4 weeks), `aaa-tools` ops will generate both:
- `registry_index.json` (v1 legacy)
- `registry_index.v2.json` (v2 new)
