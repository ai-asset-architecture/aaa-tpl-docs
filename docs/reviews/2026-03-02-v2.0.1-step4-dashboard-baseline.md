# Step4 Dashboard Baseline: v2.0.1

- date: 2026-03-02
- version: v2.0.1
- phase: Step4 pre-completion baseline
- status: APPROVED_BASELINE

## 1) Admin Information Architecture (固定 4 頁)
1. `治理總覽`：`/ops-dashboard?lang=zh-TW`
2. `版本清單`：`/ops-registry?tab=versions&lang=zh-TW`
3. `流程清單`：`/ops-registry?tab=workflows&lang=zh-TW`
4. `版本詳情`：`/ops-version/:version?lang=zh-TW`

## 2) Data Source & Truth Rules
- Canonical raw source:
  - `version_index.md`
  - `workflow_index.md`
- API source:
  - `/api/ops/registry/versions`
  - `/api/ops/registry/workflows`
  - `/api/ops/version/{version}`
- Rule: 前端不得繞過 API 自建平行 truth。

## 3) Version Detail 必備顯示（對齊 v1.3.69）
- 固定顯示 `Step1~Step4` 區塊。
- 每區塊最少欄位：
  - `title`
  - `status`
  - `artifacts[]`
- Step2 另有：
  - `run_ref`
  - `run_url`（可解析時）
- 無資料時必須顯示 `UNVERIFIED` 或 `N/A`，不可空白。

## 4) Step4 Completion Gate
僅當以下條件同時成立，Step4 才可 PASS：
1. 在 AAA 目標環境（localhost:9003）可開啟 4 頁路由。
2. MCP 驗證 Global 5 頁（含 header）全 PASS。
3. `v2.0.1` 版本頁可顯示 Step1~Step4 全區塊（非「未同步到版本索引」）。
4. completion report 與 run evidence 相互可追溯。

## 5) Non-Goal
- 本檔僅定義 Step4 驗收基準，不宣稱 Step4 已完成。
