## What are Templates?

**Templates** are standardized document structures for:
- ✅ **Project Documentation**: PRD, ADR  
- ✅ **Governance**: Checklists, setup guides
- ✅ **Validation Reports**: Version validation framework

## Usage Examples

### Using PRD Template
```bash
cp aaa-tpl-docs/templates/PRD-template.md \
   my-project-docs/PRD.md
```

### Using ADR Template
```bash
cp aaa-tpl-docs/templates/ADR-template.md \
   my-project-docs/architectural-decisions/ADR-001.md
```

### Using Validation Template
```bash
cp aaa-tpl-docs/templates/validation/version_validation_report_template.md \
   internal/development/audits/v1.1_validation_report.md
```

## Template Structure

### Document Templates
- Clear sections with placeholder text
- Formatted in Markdown
- Minimal but complete

### Checklist Templates
- Checkbox format (`- [ ]`)
- Step-by-step instructions
- Links to relevant docs

---

## Creating Custom Templates

1. **Follow AAA format**:
   - YAML frontmatter (if applicable)
   - Clear section headers
   - Placeholder text in `<angle brackets>`

2. **Place in correct directory**:
   - General: `templates/`
   - Category-specific: `templates/<category>/`

3. **Document usage** in this catalog
