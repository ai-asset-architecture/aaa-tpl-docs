# AAA v0.8 Marketplace Assets Design

**Goal:** Define the marketplace asset architecture (packs + registry + loader) with clear data flow, namespacing, and install paths.

**Scope:** v0.8 (public registry only). Private registry fields are reserved but not implemented.

---

## Architecture Overview

```
Registry Repo (public)
  └─ registry_index.json  ──>  aaa pack list/install

Repo Local
  └─ .aaa/packs/<pack-id>/<version>/
       ├─ pack.manifest.json
       ├─ checks/
       ├─ templates/
       └─ rules/

CI / Repo Checks
  └─ pack_loader.py  ──>  discover_pack_checks  ──>  run_repo_checks
```

Key idea: **Pack Loader is the bridge**. It scans installed packs, namespaces check ids, and feeds repo-checks without modifying the core loop.

---

## Data Flow

1) **List Packs**
   - CLI pulls `registry_index.json` and renders available packs.

2) **Install Pack**
   - CLI resolves pack version → downloads artifact → extracts to `.aaa/packs/<id>/<version>/`.
   - Writes `.aaa/packs/installed.json` ledger (id, version, source, checksum, installed_at).

3) **Repo Checks**
   - `pack_loader.py` scans `.aaa/packs/*/*/checks/`.
   - Each discovered check is **namespaced** as `<pack-id>::<check-id>`.
   - `run_repo_checks.py` executes core checks + pack checks.

## Registry Index (Reserved Private Fields)

`registry_index.json` uses a `registries` section to reserve future private types:

```json
{
  "version": "1.0",
  "registries": {
    "official": {
      "type": "github-public",
      "url": "https://raw.githubusercontent.com/.../registry_index.json"
    }
  },
  "packs": {
    "agent-safety": {
      "latest": "1.0.0",
      "versions": {
        "1.0.0": "https://github.com/.../releases/download/agent-safety-v1.0.0/pack.zip"
      },
      "requires": ["aaa-tools>=0.8.0"],
      "applies_to": ["agent", "genai-service"]
    }
  }
}
```

---

## Pack Structure

Packs are zip/tar artifacts with a manifest and content directories:

```
pack-agent-safety/
├── pack.manifest.json
├── checks/
├── templates/
└── rules/
```

Manifest fields: id, version, content paths, applies_to, requires, checksum.

---

## Namespacing Strategy

To avoid conflicts with core checks, **pack checks are namespaced**:

- Core check: `lint`
- Pack check: `agent-safety::secret_scan`

This allows report attribution and prevents overwriting core ids.

---

## Non-Goals (v0.8)

- Private registry auth
- Billing / marketplace UI
- Pack signing / verification

---

## Implementation Hooks

- `aaa-tools` adds `aaa pack build/list/install/show`.
- `aaa-evals/runner/pack_loader.py` for pack discovery and namespacing.
- `repo-checks` includes pack checks in execution list.
- CI smoke test installs a pack and runs `repo-checks`.
