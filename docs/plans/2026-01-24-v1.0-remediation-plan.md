# AAA v1.0 Remediation Plan (2026-01-24)

## Goal
針對 v0.4→v1.0 roadmap 缺口，列出可執行的修補項目，並明確交付與驗證方式。

## Priority P0 (必補治理與企業落地)

### P0-1 企業級 SOP 套件（含導入清單 + RACI）
**Dependencies:** None (foundational)
- **Deliverables**
  - `aaa-tpl-docs/docs/enterprise/sop_kit.md`
  - `aaa-tpl-docs/docs/enterprise/raci_matrix.md`
  - `aaa-tpl-docs/docs/enterprise/adoption_checklist.md`
- **Validation**
  - 內容對齊 `aaa-tools/specs/CLI_CONTRACT.md`
  - 列出角色責任與導入步驟

### P0-2 年度治理審核報告模板
**Dependencies:** P0-1 (needs RACI/roles for audit ownership)
- **Deliverables**
  - `aaa-tpl-docs/templates/audit/annual_governance_audit_template.md`
- **Validation**
  - 包含年度範圍、檢查清單、證據鏈欄位、責任人欄位

### P0-3 Org-level onboarding Evals 強制證據
**Dependencies:** P0-1 (SOP baseline) can run in parallel once SOP/RACI is drafted
- **Deliverables**
  - `aaa-tpl-docs/reports/audits/org_onboarding_evals_enforced_YYYYMMDD.md`
- **Validation**
  - `aaa init repo-checks --suite governance` 的 org-level 結果與證據

## Priority P1 (可重複交付能力)

### P1-1 Template Registry 落地
**Dependencies:** P0 complete (governance baseline ready)
- **Deliverables**
  - `ai-asset-architecture-registry/template_registry.json`
  - `aaa-tpl-docs/docs/registry/template_registry.md`
- **Validation**
  - 至少一個 template 註冊案例

### P1-2 Pack Portfolio 擴充（≥3）
**Dependencies:** P1-1 (registry/index in place)
- **Deliverables**
  - 新增 2 個 pack（基礎治理 / 行業特化）
  - 更新 `ai-asset-architecture-registry/registry_index.json`
- **Validation**
  - `aaa pack list` 顯示 ≥3 packs
  - `aaa pack install <pack>` 成功

### P1-3 Org Audit Pack / Release Integrity Pack
**Dependencies:** P1-1 (registry) and P1-2 (pack workflow) can proceed in parallel after registry is ready
- **Deliverables**
  - `ai-asset-architecture-registry/packs/org-audit@1.0.0`
  - `ai-asset-architecture-registry/packs/release-integrity@1.0.0`
- **Validation**
  - pack checks 能被 repo-checks 載入

## Priority P2 (自動化與觀測擴充)

### P2-1 Observability 指標與告警
**Dependencies:** v0.9 dashboard MVP (already complete); can run parallel with P1 after P0
- **Deliverables**
  - `aaa-tools/aaa/ops/render_dashboard.py` 擴充 drift/repo health
  - `aaa-tpl-docs/docs/dashboard/index.html` 顯示新指標
  - `aaa-actions` nightly workflow 加入告警門檻
- **Validation**
  - Nightly workflow 至少連續穩定運行 1–2 週，累積足夠歷史資料
  - dashboard 顯示 drift/repo health 時序
  - 觸發 threshold 時 workflow 失敗

### P2-2 ops/init-milestone + actions-reference
**Dependencies:** P1 registry/pack baseline (action catalog should source registry)
- **Deliverables**
  - `aaa-tools/runbooks/ops/init-milestone.yaml`
  - `aaa-tools/templates/actions-reference.md.tmpl`
  - `aaa-tpl-docs/docs/actions-reference.md`
- **Validation**
  - runbook 可生成 milestone 索引
  - actions-reference 可由 registry 產出

### P2-3 Upgrade/Audit Runbooks + Pipeline
**Dependencies:** v0.5 runbook baseline; can run in parallel with P2-1 after P0
- **Deliverables**
  - `aaa-tools/runbooks/repo/upgrade.yaml`
  - `aaa-tools/runbooks/repo/audit.yaml`
  - `aaa-actions` pipeline 對應 workflow
- **Validation**
  - runbook schema 驗證通過
  - pipeline 可成功執行
