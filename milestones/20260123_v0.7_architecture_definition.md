# Milestone: v0.7 Architecture Definition (20260123)

Status: Completed
Completed At: 2026-01-23 10:30 (Asia/Taipei)

## Summary
v0.7 將治理規則從 heuristic 收斂為 SSOT 與明確宣告：以 `checks.manifest.json` 固定 required checks 名稱與適用範圍，並把 `repo_type` 持久化到 `index.json` 以驅動 repo-checks 的情境判斷。

## Architecture Definition
- Checks SSOT：`aaa-actions/checks.manifest.json` 成為 required checks 的唯一真相，支援 `applies_to` 過濾。
- Repo Type Persistence：`repo_type` 寫入 repo 根目錄 `index.json`，成為長期治理上下文。
- Context-aware Repo Checks：`aaa-evals` 讀取 `repo_type`，決定是否要求 `skills/` 與 `prompt.schema.json`。
- v0.7 Plan：新增 `plan.v0.7.json`，避免覆寫既有 v0.1 行為。

## Why This Matters
- 防止 required checks 名稱漂移造成規則死鎖。
- 讓治理規則具備可追溯、可持久的上下文來源。
- 降低非 agent repo 誤判，提升 CI 訊噪比與可信度。
