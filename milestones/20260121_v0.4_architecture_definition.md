# Milestone: v0.4 Architecture Definition (20260121)

## Summary
v0.4 建立治理核心與 CLI 合約雙層對齊，將 SOP 與 post-init audit 納入可驗證的閉環流程。

## Architecture Definition
- Dual Contract Alignment：SOP 與 CLI contract 對齊可被自動驗證。
- Post-init Audit：初始化後必須執行 repo-checks，形成治理閉環。
- Eval Enforcement：新增 `cli_contract_sync` 與 `post_init_audit_required` 檢查作為基線。
- Runbook Linkage：SOP 與契約文件明確連結 post-init runbook。

## Why This Matters
- 讓文件與實作一致性可被系統驗證，降低漂移風險。
- 初始化後的治理狀態可稽核，形成可信的交付基線。
