# AAA v1.2 Release: Semantic Registry

> **Date**: 2026-01-28
> **Status**: ✅ Completed
> **Focus**: Object-Centric Governance & Natural Language Capabilities

## 1. Executive Summary
AAA v1.2 (Semantic Registry) 標誌著 AAA 從「靜態列表」向「智能作業系統」的關鍵轉型。本次更新引入了三大核心機制：
1.  **Object-Centric Governance**: 透過 `object_type` 定義（如 Service, Library, Data Pipeline），專案能自動繼承對應的治理包 (Packs) 與評估標準 (Evals)。
2.  **Semantic Capabilities**: Registry 現在支援自然語言能力描述，Agent 可透過 `aaa registry query` 進行語義搜尋（如 "find packs for security"）。
3.  **Version Handshake**: 實施 `min_cli_version` 檢查機制，確保 Client 與 Registry Schema 的兼容性，落實 "Fail Fast" 安全策略。

## 2. Key Deliverables
- **Registry Schema v2.0**: 完整定義了 `ObjectType` 與 `RegistryPack` 模型，支援繼承與依賴。
- **Seed Registry**: 初始化了 `service`, `library`, `data-pipeline`, `infra-as-code` 四大核心物件類型。
- **Intelligent CLI**: 新增 `aaa registry query` 指令，支援 Capability Matching 與 ID Matching。
- **Safety First**: 嚴格的 CLI 版本交握機制，防止因版本落後導致的治理漏洞。

## 3. Impact
- **For Agents**: 大幅降低 Agent 尋找合適工具的門檻，提升自主完成任務的成功率。
- **For Developers**: 透過 Object Type 自動套用治理規範，減少手動配置錯誤。
- **For Architecture**: 為 v1.5 的 RAG 增強與 v2.0 的 Agent OS 自癒能力奠定完備的數據基礎。
