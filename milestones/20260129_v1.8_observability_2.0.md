# Milestone: v1.8 Observability 2.0

**Status**: COMPLETED  
**Date**: 2026-01-29  
**Version**: 1.8.0  

## Executive Summary
AAA v1.8 引入 **"Observability 2.0" (可觀測性 2.0)**，將治理從靜態的「快照檢查」轉變為動態的「時序監控」。
核心引入 **MetricStore (SQLite)** 與 **RiskLedger (Privacy-Aware Log)**，並提供 CLI ASCII 趨勢圖，讓治理成效可視化、可追蹤。

## Key Deliverables
1.  **MetricStore (Time-Series)**:
    -   SQLite-based 指標儲存，支援 90 天自動 retention。
    -   記錄 Compliance Score、Test Coverage 等關鍵指標趨勢。
2.  **RiskLedger & Privacy Firewall**:
    -   **Critical**: 在寫入硬碟前自動 scrub 敏感資訊 (e.g., `admin/********`)。
    -   Tamper-Evident Hashing (SHA256) 確保稽核紀錄不可竄改。
3.  **Trend Visualization (`aaa observe trends`)**:
    -   CLI 原生 ASCII Sparklines，无需 Web UI 即可檢視趨勢。

## Impact
-   **數據驅動治理**: 從「感覺合規」進步到「數據合規」。
-   **安全升級**: Privacy Firewall 確保治理工具本身不會成為資安漏洞。
