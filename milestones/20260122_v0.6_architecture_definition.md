# Milestone: v0.6 Architecture Definition (20260122)

## Summary
v0.6 建立 Agent Safety 的驗證與執行邊界：Action Registry 能回傳標準錯誤碼、Runbook CLI 支援 JSON 輸出與檔案執行、並以安全測試套件驗證 scope 與 path traversal 防護。

## Architecture Definition
- Action Registry：明確 scopes 與錯誤碼，供安全測試與 CLI 回傳結構化結果。
- JSON Runtime Output：`aaa run runbook` 支援 `--json` 與 `--runbook-file`，提供機器可判讀結果。
- Path Traversal Guard：`fs_write` 強制限制在 repo root 範圍內，違規回報 `PATH_TRAVERSAL`。
- Agent Safety Evals：新增攻擊型 runbooks + suite/cases，將「預期失敗」作為 PASS 條件。

## Why This Matters
- 讓安全驗證可被 CI 重複執行，避免「人為判斷安全」。
- 提供可機器判讀的錯誤碼與驗證結果，利於後續自動化與稽核。
- 將安全測試資產化，形成可擴展的紅隊測試基線。
