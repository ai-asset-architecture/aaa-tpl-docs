# Milestone: v0.5 Architecture Definition (20260122)

## Summary
v0.5 建立 Runbook Runtime 與標準化 Action Library，讓治理流程可被執行、可被追溯，並為自動化結案與索引回填打下基礎。

## Architecture Definition
- Runbook as Code：以 schema + registry 定義 runbook 資產，支援版本化與 checksum 驗證。
- Runtime Engine：CLI 能執行 runbook，完成變數代換、步驟派送與執行紀錄。
- Standard Action Library：提供 `fs_write`, `fs_update_frontmatter`, `governance.update_index`, `notify`, `aaa_evals.run` 等原子動作。
- 索引自動化：治理目錄輸出 `README.md` + `index.json`，建立人機雙入口索引。
- 結案協議（Closing Protocol）：里程碑完成需綁定驗證結果與定義檔 hash，形成可稽核的閉環。

## Why This Matters
- 從「文件規範」升級到「可執行的治理流程」。
- Runbook 與 Action 解耦，讓自動化可組合且可擴展。
- Index 與 Completion Evidence 讓治理結果可追溯、可重放。
