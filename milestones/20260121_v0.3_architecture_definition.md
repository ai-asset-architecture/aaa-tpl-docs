# Milestone: v0.3 Architecture Definition (20260121)

## Summary
v0.3 建立 onboarding 文件一致性治理與 CI 穩定性補強，將「文件/流程漂移」納入可驗證的架構層。

## Architecture Definition
- Onboarding drift 檢查成為治理標準：跨 `.github` 與 `aaa-tpl-docs` 的版本/指令一致性可自動驗證。
- SOP 與 Start Here 的一致性要求成為基線（版本與指令對齊）。
- Playbook repo 地圖定義採「Maximal Set」語義，避免固定 repo 數字誤讀。
- Eval workflow 明確建立 Python 執行環境，提升驗證穩定性。
- Onboarding prompt 與模板資產納入標準化資產池，支援審查與快速啟動。

## Why This Matters
- 文件與流程漂移從人為檢查轉為系統治理，降低新成員導入風險。
- 架構從「規則敘述」升級為「可驗證的執行與審查資產」。
- v0.3 建立 v1.0 全自動治理的前置基線。
