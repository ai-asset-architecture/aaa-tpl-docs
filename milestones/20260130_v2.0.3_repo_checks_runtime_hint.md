# v2.0.3 Milestone: Repo-Checks Runtime Hint (2026-01-30)

> **Status**: ✅ **COMPLETED**
> **Goal**: Ensure post-init governance validation is visible to humans/agents at repo creation time via CLI runtime hints.

## Executive Summary
**ZH-TW:** v2.0.3 將「repo-checks 必跑」改為 CLI 成功輸出的一部分，讓新 repo 建立完成後即刻看到 post-init 治理驗證提示，降低人/AI 遺漏治理步驟的風險。

**EN:** v2.0.3 adds a post-init repo-checks hint to successful CLI flows, ensuring humans and agents see the governance validation requirement immediately after repo creation.

## Key Deliverables
1. **Standardized Post-init Hint**
   - A shared CLI message defines the required `aaa init repo-checks --suite governance` step.
2. **CLI Success-Path Output**
   - `aaa init` and `aaa init enterprise` now emit the hint after successful completion.
3. **Audit Evidence**
   - Manual verification logged with command output and timestamp.
