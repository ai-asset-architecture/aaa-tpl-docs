# Milestone: v0.2 Architecture Definition (20260120)

## Summary
v0.2 將 AAA 從「可用」提升為「可治理、可路由、可降級」的可執行架構，並建立技能決策樹與治理驗證基線。

## Architecture Definition
- Skills v0.2 決策樹標準：Routing / Rules / Fallback + Execution Test 為必要結構。
- Triage 根節點：以 `aaa-triage` 作為任務分流入口。
- 治理驗證擴充：新增 `skill_structure_v2` 檢查並納入 Execution Test。
- 可執行測試基線：`common/aaa-*` 補齊 `tests/smoke.sh`。
- Onboarding 安全流程：SOP v0.2 與 Start Here 同步，納入 auth/下載/JSON sanity/雙路徑流程。
- 資產回饋流程：新增 asset contribution SOP 與報告索引，形成回流閉環。

## Why This Matters
- 架構從「文件規範」升級為可執行、可驗證的治理系統。
- 路由/降級能力讓技能可在不同模型環境中可靠運作。
- Onboarding 流程與治理驗證成為可持續擴充的基線。
