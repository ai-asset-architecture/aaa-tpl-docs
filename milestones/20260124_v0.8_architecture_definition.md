# v0.8 Architecture Definition — Marketplace Assets

## Goal
將 AAA 從單體治理框架擴展為「可插拔資產市場」，支援 Pack 的打包、發布與安裝。

## Key Deliverables
- Pack 架構（`pack.manifest.json`）與打包流程（`aaa pack build`）
- Registry 協議與索引（`registry_index.json`）
- Repo Local 安裝路徑（`.aaa/packs/`）與安裝紀錄（`installed.json`）
- Pack 可被 repo-checks 載入並執行（namespaced checks）

## Success Metrics
- `aaa pack install agent-safety@1.0.0` 可重現安裝
- Pack checks 可被 repo-checks 自動載入並通過 smoke test
- Registry index 與 release asset 連結可追溯

## Scope Boundaries
- In scope：公開 Registry、Repo Local 安裝
- Out of scope：私有 Registry / Auth / Billing
