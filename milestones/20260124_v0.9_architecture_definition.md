# v0.9 Architecture Definition — Governance Compliance Dashboard

## Goal
建立以 nightly-governance 為單一數據來源的「治理合規率儀表板」，以 repo 為分母計算合規率，並提供 Markdown 稽核底稿與 GitHub Pages 視覺化。

## Key Deliverables
- Nightly Scan 產出 `nightly_governance.json`（原始數據），支援 archived 標記與 repo_type。
- 合規率公式：Repo-based，`compliant = 所有 checks == "pass"`；`fail`/`error` 視為不合規。
- Markdown 報告：`reports/audits/YYYY-MM-DD-governance.md`（稽核底稿）。
- GitHub Pages 儀表板：`docs/dashboard/index.html`（可視化）。
- 告警門檻：`compliance_rate < 0.8` 觸發 workflow failure。

## Success Metrics
- 每日產出 Markdown + HTML 兩種視圖，資料一致。
- Archived repo 在報告中呈現為 N/A，不納入合規率分母。
- 合規率可被穩定追蹤並用於管理層 KPI。

## Scope Boundaries
- In scope：Nightly 聚合、Markdown 報告、GitHub Pages 儀表板、閾值告警。
- Out of scope：即時事件流、外部 BI 平台、跨組織匯總。
